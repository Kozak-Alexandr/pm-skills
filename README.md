# Скиллы Claude Code для продакт-менеджеров

Два инструмента, которые вызываются из чата с Claude Code обычной фразой.

| Скилл | Что делает | Как вызвать |
|---|---|---|
| `meeting-transcribe` | Запись встречи → стенограмма со спикерами, саммари, решения, задачи, HTML-отчёт с плеером и PDF. Две модели распознавания на каждый фрагмент (GigaAM v3 и Whisper large-v3), сведение через LLM по словарю вашего продукта. Распознавание локальное | «расшифруй встречу C:\...\запись.mp3» |
| `pain-registry` | Обратная связь из интервью, встреч, тикетов → бэклог, где у каждого пункта видно число разных клиентов и их дословные цитаты. Приоритет по прозрачной формуле. Можно прямо в чате или через веб-интерфейс | «собери бэклог из интервью в папке C:\...» |

Вместе они складываются в цепочку: расшифровал встречи, потом собрал из них бэклог.

## Установка

```
git clone https://github.com/Kozak-Alexandr/pm-skills.git
cd pm-skills
powershell -ExecutionPolicy Bypass -File install.ps1
```

На macOS и Linux скопируйте папки из `skills/` в `~/.claude/skills/`.

Потом перезапустите Claude Code.

**LLM.** Для сведения текста и саммари нужен любой OpenAI-совместимый API: адрес, ключ и модель в `~/.llm.env`. Если файл не заполнить, расшифровка использует Claude Code CLI (`claude -p`).

**Окружение для расшифровки.** Нужны torch и модели распознавания, около 6 ГБ. При первой просьбе расшифровать встречу Claude предложит их поставить (`skills/meeting-transcribe/scripts/setup.ps1`, Windows). Лучше с видеокартой NVIDIA: на ней час записи обрабатывается за 30-40 минут, без неё в разы дольше. Для разделения на спикеров нужен бесплатный токен Hugging Face, Claude подскажет, где его взять.

## Где что лежит

- Код скиллов: `~/.claude/skills/<скилл>`. Обновление: `git pull` и снова `install.ps1`.
- Данные: `~/meeting-transcribe` (отчёты, словарь продукта, база людей и задач) и `~/pain-registry` (реестры и данные интерфейса). Обновление скиллов их не трогает.
- Настройки LLM: `~/.llm.env`, общие для обоих скиллов.

## Конфиденциальность

Распознавание речи и интерфейс реестра работают на вашем компьютере. Текст встреч уходит только той LLM, которую вы настроили. В режиме «прямо в чате» реестр читает тексты встреч сам Claude: для данных клиентов под NDA он сначала спросит, можно ли так.

## Модели и лицензии

- [GigaAM](https://github.com/salute-developers/GigaAM) (MIT), [faster-whisper](https://github.com/SYSTRAN/faster-whisper) и Whisper large-v3 (MIT), [pyannote.audio](https://github.com/pyannote/pyannote-audio) (MIT; модель community-1 требует принять условия на Hugging Face), [Silero VAD](https://github.com/snakers4/silero-vad) (MIT).
- В интерфейсе реестра: [JSZip](https://stuk.github.io/jszip/) (MIT) и [pdf.js](https://mozilla.github.io/pdf.js/) (Apache 2.0), их лицензии лежат рядом с файлами.
