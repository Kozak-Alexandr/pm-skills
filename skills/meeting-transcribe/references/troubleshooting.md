# Если что-то пошло не так

## Установка

- **torch качается часами.** Корпоративный прокси может резать одну закачку до 0,3-1 МБ/с. Скачай колесо torch вручную в несколько потоков (так `download_whisper.py` качает модель) и поставь из файла: `uv pip install <путь к .whl>`.
- **Внутреннее зеркало PyPI недоступно.** Ставь с публичного индекса: `--index-url https://pypi.org/simple` (так сделано в `setup.ps1`).
- **Предупреждение torchcodec «Could not load libtorchcodec».** На Windows это нормально: звук передаётся в pyannote из памяти, библиотека не нужна.

## Распознавание

- **Не хватает видеопамяти, всё ползёт.** На картах с 6 ГБ батч Whisper 8 переполняет память, и драйвер начинает свопить. По умолчанию батч 4; если памяти меньше, поставь `WHISPER_BATCH=2`.
- **Скачивание GigaAM падает с 503.** CDN иногда отвечает 503 через прокси; повтори запуск, загрузка повторяется сама.
- **Вся встреча на одного спикера.** Нет `HF_TOKEN` в `~/meeting-transcribe/.env` или не приняты условия модели pyannote.

## LLM

- **`Connection error` и долгое зависание до корпоративного шлюза.** Если прокси не пускает к внутреннему хосту, добавь в `~/.llm.env` строку `LLM_NO_PROXY=1`: клиент пойдёт напрямую.
- **`CERTIFICATE_VERIFY_FAILED`.** Шлюз подписан внутренним сертификатом, которого нет в системе. Положи цепочку в файл и укажи путь: `LLM_CA_BUNDLE=C:\путь\chain.pem`.
- **`claude CLI не залогинен`.** Запусти `claude` в обычном терминале и выполни `/login`, либо настрой API в `~/.llm.env`.
- **Пустой ответ модели Qwen.** Qwen иногда тратит весь бюджет на размышление; на последней попытке клиент выключает размышление сам. Если повторяется, `CORRECT_THINKING=0` ускорит сведение ценой качества.
- **Текст похож на сырую версию одной модели, с «э-э».** На длинных пачках модель «ленится» и копирует одну из версий. Пачки по 20 фрагментов и размышление включены по умолчанию, не увеличивай `BATCH` в `process.py`.
