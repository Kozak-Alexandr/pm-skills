# Реестр болей

Конвейер «обратная связь любого формата → бэклог с происхождением». Каждый пункт бэклога раскрывается в темы, тема - в дословные цитаты клиентов, цитата - в реплику исходного файла с таймкодом.

## Запуск

Нужен только Python 3.9+, без pip-зависимостей.

```
run.bat                 (Windows)
./run.sh                (Linux/macOS)
python server.py --port 8095
```

Откроется `http://127.0.0.1:8095`. Начните с вкладки «Источники»: добавьте файлы или папку и запустите конвейер.

## Модель

**Модель настраивается один раз.** При первом запуске создаётся `~/pain-registry/config.json`, а адрес, ключ и модель берутся из общего файла `~/.llm.env` (`LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`). Сам ключ в `config.json` не копируется. Без модели прототип работает на эвристике.


Подходит любая OpenAI-совместимая модель: внутренняя LLM в контуре, vLLM, Ollama, облачный API. Настраивается в `config.json` (копия `config.example.json`) или прямо в интерфейсе, вкладка «Настройки»:

| Поле | Что это |
|---|---|
| `base_url` | Адрес API, например `http://llm.internal:8000/v1` или `http://localhost:11434/v1` для Ollama |
| `api_key` | Ключ; хранится только на сервере, в браузер не передаётся |
| `model` | Имя модели |
| `stt_model` | Модель распознавания речи для аудио и видео (`/audio/transcriptions`), необязательно |
| `json_mode` | Просить `response_format: json_object`; если сервер не умеет, прототип повторит без него |
| `env_file` | Путь к `.env`, откуда взять `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_DEFAULT_MODEL` |
| `use_system_proxy` | `false` - ходить к модели напрямую, мимо системного прокси |
| `ca_bundle` | Корневой сертификат, если его нет в системном хранилище |
| `extra_body` | Дополнительные поля запроса, например `{"chat_template_kwargs": {"enable_thinking": false}}` для Qwen |
| `allowed_roots` | Папки, из которых разрешено импортировать файлы целиком |
| `price_*_rub_per_1m` | Цены за миллион токенов - для расчёта стоимости прогона |

Можно и через переменные окружения: `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`, `LLM_STT_MODEL`.

Без модели прототип тоже работает: извлечение и темы делает эвристика на ключевых словах. Это и есть бейзлайн для сравнения.

## Форматы

`txt` (в том числе расшифровки Контур.Толк, Teams, Zoom с таймкодами и спикерами), `md`, `docx`, `pdf`, `pptx`, `xlsx`, `csv`, `tsv`, `json`, `vtt`, `srt`, `html`, `eml`. Аудио и видео (`mp3`, `m4a`, `wav`, `ogg`, `mp4`) - если задан `stt_model`.

Таблицы (выгрузки тикетов и фича-реквестов) разбираются построчно: колонка с текстом, клиентом, автором и датой определяется по заголовкам.

## Ступени конвейера

1. **Нормализация.** Глоссарий исправляет искажённые расшифровкой термины («джира» → Jira). Реплики нашей команды помечаются и не считаются обратной связью клиента.
2. **Извлечение.** Модель находит атомарные единицы: дословная цитата, суть, тип (боль, запрос, блокер сделки, похвала, вопрос), категория из постоянной таксономии, критичность.
3. **Сверка цитат.** Каждая цитата ищется в исходнике. Не найденные помечаются и в бэклог не попадают.
4. **Темы.** Единицы группируются в темы; уже существующие темы переиспользуются, чтобы таксономия не плыла между прогонами.
5. **Бэклог.** Модель формулирует задачи с критериями приёмки, а приоритет считает прозрачная формула: внешние клиенты, внутренние источники, блокеры сделки, критичность, свежесть.

Параллельно на тех же источниках работает бейзлайн на ключевых словах - для вкладки «Качество».

## Разметка и метрики

Откройте источник, отметьте найденные единицы «верно» или «ошибка», выделите пропущенный фрагмент и нажмите «Добавить как обратную связь», поставьте галочку «Эталон». Вкладка «Качество» считает точность, полноту и F1 модели против бейзлайна, долю дословных цитат и долю реплик вендора, принятых за клиентские. Разметка выгружается в CSV - это вход в Data Plan на Gate 4.

## Где хранятся данные

`~/pain-registry/data/workspace.json` (папку можно поменять переменной `PAIN_REGISTRY_HOME`). Наружу ничего не уходит, кроме вызовов к указанной вами модели.
Как это делают другие

Схема повторяет индустриальную: импорт и нормализация → атомарные «хайлайты» с цитатой → устойчивая таксономия-кодбук → темы → решения с трассировкой до исходной реплики (Dovetail, Condens, Enterpret). Отличие - работа в контуре, доменный глоссарий для расшифровок и счёт разных клиентов вместо упоминаний.
